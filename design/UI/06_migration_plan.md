# 06. 移行計画

## フェーズ1: エンドユーザーUIの追加

- `/u` ルートとテンプレを追加
- レシピ定義を導入し、`recipe_id` を Run に保存
- 成果物のアクセス制限を `/u` 側で適用

## フェーズ2: 運用分離

- `/admin` と `/api` を運用で非公開にする
- エンドユーザーは `/u/*` のみ利用

## フェーズ3: UX改善

- 依頼文のテンプレ改善
- 成果物プレビューの強化（Markdown整形、ハイライト）
- 実行中の進捗表示（ステップ名や簡易ステータス）

## フェーズ4: 認証の検討

- 本格的な認証（OIDC/SSO）を導入する場合は `/admin` と `/u` の権限分離を明確化
