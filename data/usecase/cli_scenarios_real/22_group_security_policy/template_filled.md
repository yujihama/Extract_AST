# 規程間の主な不整合一覧（全社横断）
1. パスワード強度: グループ=12文字以上、製造/小売=8文字、IT/金融=14文字 → 統一が必要
2. MFA適用範囲: 製造=検討、小売=店舗対象外、IT/金融=全社適用 → 重要情報・リモートアクセスは全社MFA必須化推奨
3. 退職・異動時のアカウント無効化: グループ=当日中、製造=3営業日、小売="速やかに"（定義曖昧） → 当日中運用へ統一
4. ログ保管期間: 90日/180日/3年/7年 とばらつき → 最低365日を全社標準、業法準拠要件は個別上乗せ
5. 委託先の再委託管理: 製造/小売は緩め、IT/金融は事前承認制 → 全社で事前承認＋年次評価へ
6. インシデント報告期限: 30分～48時間と幅広い → 重大インシデントは24時間以内にグループCISO報告（金融は更に短縮）
7. 例外管理の要件: 台帳・期限・リスク評価の有無で差異 → 全社で例外管理台帳・期限・リスク評価の必須化
