提案者: Bシステムインテグレーション株式会社（架空）

会社名: Bシステムインテグレーション株式会社
設立: 1995年
従業員数: 2,500名
資本金: 20億円
主要顧客: 製造業、流通業、サービス業

クラウド移行実績:

- 大手小売チェーン（2024年、POS・在庫管理システム移行）
- 中堅製造業複数社（2023-2024年、計8社）

認証取得:
- ISO 27001
- ISO 27017（クラウドセキュリティ）
- SOC2 Type2

2. 提案概要

2.1 基本方針
「コスト最適化」と「運用効率化」を重視した提案

2.2 クラウド基盤
Microsoft Azure を採用
- 既存Microsoft製品との親和性
- 東日本リージョン + 西日本リージョン（DR構成）
- ハイブリッドクラウド対応

2.3 移行アプローチ
段階的移行方式を採用
- システム単位で順次移行
- リスク分散と学習効果の最大化
- 各フェーズでの振り返りと改善

3. システム構成

3.1 インフラ構成
- Webサーバー: Azure VM (D4s_v5) × 2台 + VMSS（オートスケール）
- APサーバー: Azure VM (D8s_v5) × 2台 + VMSS
- DBサーバー: Azure SQL Database (Business Critical)
- ストレージ: Azure Blob Storage + Managed Disk
- ロードバランサー: Azure Application Gateway

3.2 ネットワーク構成
- ExpressRoute (100Mbps) による専用線接続
- Azure Virtual Network + プライベートエンドポイント
- Azure Firewall によるトラフィック制御

3.3 セキュリティ対策
- 通信暗号化: TLS 1.2以上
- データ暗号化: Azure Key Vault管理のカスタマーキー
- 認証: Azure AD + MFA
- 監査ログ: Azure Monitor + Log Analytics（保存期間: 365日）
- 脅威検知: Microsoft Defender for Cloud

4. 移行計画

4.1 フェーズ構成
- Phase 1（3ヶ月）: 人事給与システム移行
- Phase 2（3ヶ月）: 会計システム移行
- Phase 3（3ヶ月）: 販売管理システム移行

4.2 移行方式
- データ移行: Azure Database Migration Service
- 段階的移行により、各システムのダウンタイムを分散
- 移行リハーサルを各フェーズで実施

4.3 ダウンタイム
各システムのダウンタイム: 12時間
- DB移行: 8時間
- 接続確認・動作確認: 4時間
※週末に実施し、業務影響を最小化

5. 運用保守計画

5.1 運用体制
- 監視: 24時間365日（リモート監視センター）
- 障害対応: 一次対応60分以内、二次対応4時間以内
- 自動化: Azure Automation による定型作業自動化

5.2 SLA
- 稼働率: 99.9%保証
- 計画停止: 月1回、4時間以内
- 障害復旧: RTO 4時間、RPO 1時間

5.3 報告
- 月次運用報告書
- 年次セキュリティレビュー

7. 費用見積

7.1 初期費用
- 設計・構築費: 2,800万円
- 移行費用: 1,200万円
- ライセンス: 含む（Azure利用料に含む）

7.2 月額費用

7.3 3年間総費用

8. 付加価値提案

- 移行後6ヶ月間の最適化支援を無償提供

- 将来のモダナイゼーション（コンテナ化、サーバーレス）への移行ロードマップ提供
