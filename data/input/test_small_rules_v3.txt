# アクセス制御規程（テスト） v3

## 1. 目的と背景
本規程は、社内システムへのアクセス制御に関する最小要件を定めるものです。
セキュリティリスクの低減とコンプライアンス遵守を目的として、本規程を改訂しました。

## 2. 適用範囲と対象者

### 2.1 適用対象
- **社員**: 正社員、契約社員を含む全社員
- **委託先**: 契約により本規程の適用が定められた委託先
- **評価環境**: 任意適用（本番環境と同等のセキュリティ要件を満たす場合）

### 2.2 適用除外
本規程は、緊急時の一時的なアクセスには適用されません。ただし、事後の承認プロセスが必要です。

## 3. 認証に関する要件

### 3.1 パスワードポリシー
| 項目 | 要件 |
|------|------|
| 最小文字数 | 16文字以上 |
| 有効期限 | 90日ごとに変更 |
| 再利用制限 | 直近12回のパスワードは再利用不可 |
| 複雑性 | 大文字・小文字・数字・記号のうち3種類以上を含むこと |

### 3.2 アカウントロックアウト
- **ロック条件**: 連続5回の認証失敗でアカウントをロック
- **ロック期間**: 60分間
- **解除方法**: 
  - 自動解除（ロック期間経過後）
  - ヘルプデスクへの申請（本人確認書類の提出が必要）

### 3.3 多要素認証（MFA）の適用
以下の場合、MFAの利用が必須となります：
1. 管理者権限を持つアカウント（全アクセス）
2. 社外ネットワークからのアクセス（一般ユーザーを含む）
3. 機密情報へのアクセス時

## 4. セッション管理

### 4.1 セッションタイムアウト
- **アイドルタイムアウト**: 30分
- **最大セッション時間**: 8時間
- **タイムアウト時の動作**: 自動ログアウト後、再認証を要求

### 4.2 同時セッション
同一アカウントからの同時ログインは最大3セッションまで許可します。

## 5. 監査とログ管理

### 5.1 ログ保持期間
- **標準保持期間**: 2年間（730日）
- **例外**: 法令や規制により別途指示がある場合は、その指示に従う

### 5.2 記録対象イベント
以下のイベントは必ず記録されます：
- ログイン・ログアウト
- 認証失敗
- 権限変更
- 機密情報へのアクセス

## 付録: 用語集

| 用語 | 説明 |
|------|------|
| MFA | Multi-Factor Authentication（多要素認証） |
| 社外ネットワーク | 社内WAN以外のネットワーク環境 |
| アイドルタイムアウト | 操作がない状態が続いた場合の自動ログアウト時間 |
